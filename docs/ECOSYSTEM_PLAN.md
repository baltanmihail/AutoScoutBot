# AutoScout Web - План Монетизации и Экосистемы (Product Radar)

## 1. Разделение функционала (Free vs Paid)

Основной принцип: мы даем инвесторам "попробовать" платформу и увидеть базовую картинку, но за детальной аналитикой и эксклюзивными проектами нужно платить.

### Базовый уровень (Free / Guest)
- Просмотр сокращенного списка ТОП-стартапов (только базовые метрики: ИНН, отрасль, ML-скоринг без объяснений).
- Ограниченный поиск по базе (до 5 запросов в месяц).
- Доступ к базовому калькулятору IRR/NPV для ручного ввода.

### Платная подписка (Pro / VC Level)
- **Полные SHAP-отчеты**: Детальная расшифровка того, *почему* стартап получил такой балл, с указанием конкретных позитивных/негативных факторов (Cash Gap, Тренд рынка, TRL).
- **Динамика рынка (Momentum)**: Доступ к сигналам из GDELT, Google Trends, Reddit (насколько "горячая" ниша прямо сейчас).
- **Скрытие/открытие контактов**: Доступ к прямым контактам фаундеров верифицированных стартапов.
- **Официальный экспертный отчет**: Возможность выгрузить детальный PDF-отчет по стартапу с нашей электронной подписью, за который мы "ручаемся" как платформа-верификатор.
- **Безлимитный доступ** к поиску и фильтрам.

## 2. Развитие Экосистемы и Комьюнити

### Внутренняя CRM для Инвесторов (Deal Flow)
- Инвесторы могут переносить стартапы из "Радара" в свой личный "Pipeline" (Kanban-доска: *Скрининг* -> *Переговоры* -> *Due Diligence* -> *Сделка закрыта*).
- Возможность оставлять личные заметки, прикреплять файлы (NDAs, Term Sheets).

### Мессенджер и Комьюнити (Networking)
- Встроенные чаты между Инвесторами и Фаундерами (открываются только после "мэтча" или запроса интро).
- **Синдикаты**: Возможность для нескольких мелких инвесторов объединяться в синдикаты прямо на платформе для инвестирования в один стартап.
- Закрытые Telegram-группы (интеграция с нашим Telegram-ботом) для пользователей уровня Pro.

---

## 3. Финансовая модель стартапов (Для фаундеров)
- Базовый скоринг для стартапа — **бесплатно** (чтобы загнать их в воронку и получить данные).
- Опция **"Улучшить профиль"**: Платная услуга по детальному разбору их слабых сторон (почему ML-модель дала низкий балл) и рекомендации по улучшению показателей перед показом инвесторам.

---

## 4. Следующие шаги для реализации
1. Внедрить систему "Кредитов" (Токенов) в базу данных `WebUser`, чтобы списывать их за генерацию SHAP-отчетов.
2. Создать эндпоинт генерации PDF (используя ReportLab или WeasyPrint).
3. Добавить Kanban-доску на Frontend для страницы "Портфель" (Pipeline).
