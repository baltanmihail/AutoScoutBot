# Opportunity Scout AI - Анализ и интеграция идей

## Обзор
**Opportunity Scout AI** — это платформа на базе искусственного интеллекта, предназначенная для оценки жизнеспособности стартапов. Она объединяет исторические данные о venture-проектах с глобальными макро- и микросигналами в режиме реального времени, чтобы предоставлять метрику «Opportunity Score» (от 0 до 100).

Ссылка на репозиторий: [Opportunity_Scout_AI на GitHub](https://github.com/lilibethlangat/Opportunity_Scout_AI.git)

## Ключевые особенности платформы

1. **Трёхслойная архитектура:**
   - Конвейер обработки данных и инженерия признаков.
   - Механизм машинного обучения (ML).
   - Объяснимый искусственный интеллект (XAI) на базе SHAP.

2. **Гибридный датасет (Источники данных):**
   - База данных из 25 000+ исторических стартапов (информация о финансировании, статус: работающий, приобретённый, закрытый).
   - **Глобальные экономические показатели:** API Всемирного банка (ВВП, инфляция по 50+ странам).
   - **Макро-сигналы и тренды:** Google Trends (рост популярности ключевых слов отрасли: "ИИ", "Финтех" и др.).
   - **Новостной фон:** GDELT (объём новостей, анализ тональности).
   - **Микро-сигналы и комьюнити:** API Reddit (метрики плотности и интереса в профильных сообществах).

3. **Модель машинного обучения:**
   - **Алгоритм:** LightGBM, отлично подходящий для высокоразмерных табличных данных.
   - **Оптимизация:** Минимизация среднеквадратичной ошибки (RMSE) относительно исторических показателей успеха стартапов.

4. **Объяснимость (Explainable AI - XAI):**
   - Использование **SHAP (SHapley Additive exPlanations)** для интерпретации результатов. Например, при высоком рейтинге система указывает на основной фактор успеха (сильный рыночный тренд, благоприятный инвест-климат).

5. **Реализация платформы:**
   - Развёрнуто как веб-приложение на FastAPI.
   - Включает инструменты "Score", "What-If" (анализ "что-если") и "Compare" (сравнение проектов).

## Что из этого стека мы можем взять для AutoScoutBot (Product Radar)?

Это решение *идеально* резонирует с нашей первоначальной задумкой. Мы можем интегрировать следующие подходы:
1. **Источники сигналов (API)**: Подключение Google Trends, GDELT, Reddit и API Всемирного банка значительно обогатит наш скоринг, сделав его динамичным и привязанным к реальности, а не только к питч-деку.
2. **Explainable AI (SHAP)**: Если мы будем использовать табличные/классические ML-модели для оценки, SHAP позволит генерировать "человекочитаемые" объяснения оценок для инвесторов.
3. **Функционал "What-If"**: Позволит фаундерам и инвесторам играть с параметрами ("а что если они привлекут еще $1М?", "а что если они сменят рынок на США?") и смотреть, как изменится их скоринг.
4. **Алгоритм LightGBM**: Отличный выбор для комбинированных табличных данных о стартапах. Мы можем использовать его совместно с нашими LLM, которые будут извлекать признаки из питч-деков, а LightGBM - предсказывать успех на основе этих признаков + макроданных.
